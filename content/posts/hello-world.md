## How this blog works

Each post is a Markdown file in `content/posts/`. Create a new one with:

```bash
hugo new content posts/my-next-post.md
```

New posts start as drafts. Set `draft: false` when you're ready to publish.

## Formatting

You get **bold**, *italics*, [links](https://gohugo.io), lists, tables, and code:

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```
