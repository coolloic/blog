## Summary

Declares Agent Framework 1.0 production-ready with stable APIs and long-term support in .NET and Python. Lists stable features, model connectors and memory backends, MCP and A2A status, migration assistants, and features still in preview.

## Key claims

- Stable in 1.0: agent abstraction and connectors, middleware, memory/context providers, graph workflows with checkpointing, five orchestration patterns, declarative YAML agents and workflows.
- Connectors: Microsoft Foundry, Azure OpenAI, OpenAI, Anthropic Claude, Amazon Bedrock, Google Gemini, Ollama.
- Memory backends: Foundry Agent Service, Mem0, Redis, Neo4j, custom.
- MCP support stable; A2A 1.0 support announced as coming soon (at 2026-04).
- Preview at 1.0: DevUI, Foundry hosted agents, AG-UI, skills, GitHub Copilot SDK and Claude Code SDK harnesses, Agent Harness.
