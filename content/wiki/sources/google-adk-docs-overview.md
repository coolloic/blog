## Summary

ADK is Google's open-source framework for building, debugging and deploying agents. The page lists five language SDKs, features from graph workflows to sessions, memory, artifacts and evaluation, broad model support, and deployment to Google Cloud.

## Key claims

- SDKs: Python (`google-adk`), TypeScript (`@google/adk`), Go (`google.golang.org/adk/v2`), Java and Kotlin.
- ADK 2.0 adds graph workflows that combine deterministic code with model reasoning; TypeScript 2.0 is GA.
- Features: multi-agent orchestration, template workflows, agent routing, function/MCP/OpenAPI tools, sessions, state, memory, artifacts, compaction, callbacks, plugins, live/voice agents.
- Model-agnostic: Gemini first, with adapters for Claude, OpenAI, Gemma, Ollama, vLLM and LiteLLM.
- Deploy locally, in containers, or to Google Cloud Agent Runtime (Agent Platform), Cloud Run or GKE.
- Built-in evaluation (criteria, user simulation, custom metrics) and a web Dev UI.
