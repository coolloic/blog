## Summary

The Semantic Kernel README now leads with the message that SK has become Microsoft Agent Framework, describes MAF as SK's enterprise-ready successor with a long-term-support commitment at 1.0, and links the SK-to-MAF migration guide. It does not itself state an end-of-support date for SK.

## Key claims

- Agent Framework is positioned as the successor to Semantic Kernel.
- MAF 1.0 carries a long-term support commitment.
- About 28.8k GitHub stars as of 2026-11.
