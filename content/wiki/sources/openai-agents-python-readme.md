## Summary

Lists the SDK's ten core concepts (agents, sandbox agents, realtime agents, voice agents, agents as tools/handoffs, tools, guardrails, human in the loop, sessions, tracing) and states the SDK is provider-agnostic. Points to a separate JS/TS SDK.

## Key claims

- Provider-agnostic: supports the Responses and Chat Completions APIs plus 100+ other LLMs.
- MIT licence; Python 3.10+; about 30.7k GitHub stars (2026-11).
- A JS/TS version lives in a separate repository (openai-agents-js).
- Sandbox agents work in a container over long horizons: inspect files, run commands, apply patches, keep workspace state.
