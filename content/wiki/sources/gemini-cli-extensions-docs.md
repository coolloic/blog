## Summary

The Gemini CLI counterpart to Claude Code and Codex plugins.

## Key claims

- An extension can bundle prompts, MCP servers, custom commands, themes, hooks, sub-agents and agent skills.
- Install with `gemini extensions install <github-url>`; list with `/extensions list` or `gemini extensions list`.
