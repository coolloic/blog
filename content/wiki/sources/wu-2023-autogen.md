## Summary

Introduces AutoGen, an open-source framework where applications are built from multiple customisable agents that converse to solve tasks. Developers program interaction patterns in natural language and code; agents can combine LLMs, human input and tools.

## Key claims

- Agents are customisable and conversable and can operate in several modes (LLM, human, tool-backed).
- Conversation programming defines flexible interaction patterns in natural language and code.
- Evaluated on maths, coding, QA, operations research, online decision-making and entertainment.
