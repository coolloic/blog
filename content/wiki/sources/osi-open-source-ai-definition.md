## Summary

Defines what an open-source AI system must provide, extending the classic open-source freedoms to models.

## Key claims

- Grants four freedoms: use for any purpose, study, modify, share.
- The preferred form for modification must include data information (enough to build a substantially equivalent system), complete training and inference code, and the parameters.
- Releasing weights without data information and code does not meet the definition.
