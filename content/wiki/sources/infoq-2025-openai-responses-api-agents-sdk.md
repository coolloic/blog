## Summary

Reports the launch of the Responses API (merging Chat Completions and Assistants capabilities), built-in web search, file search and computer-use tools, and the open-source Agents SDK. Notes the Assistants API deprecation plan and community concerns about lock-in.

## Key claims

- The Agents SDK succeeds Swarm, OpenAI's experimental orchestration framework.
- Launch features: multiple agents, handoffs, input/output guardrails and trace visualisation.
- Compatible with any Chat Completions-style API, including third parties.
- Computer use scored 38.1% on OSWorld at launch, so it was not yet reliable for OS automation.
- OpenAI announced the Assistants API would be deprecated the following year (2026).
- Some developers warned that adopting the SDK outsources state management to a vendor.
