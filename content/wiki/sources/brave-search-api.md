## Summary

Brave sells API access to its own crawled and ranked index, with no fallback to Google or Bing, plus an answer endpoint and an LLM-context endpoint aimed at agents.

## Key claims

- Independent index built by Brave, partly from opt-in user signals (Web Discovery Project); no absolute index size is published.
- Endpoints: web, news, images, videos, places, LLM Context (extracted page content for grounding, budget roughly 1k-33k tokens), Answers (cited summaries via an OpenAI-compatible chat interface).
- Pricing (2026-11): Search $5 per 1,000 requests at up to 50 QPS; Answers $4 per 1,000 requests plus $5 per million tokens at 2 QPS; $5 monthly free credit on each; Enterprise custom with full zero data retention.
- Storing results or training models on them requires a custom plan with storage rights.
