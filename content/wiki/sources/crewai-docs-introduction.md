## Summary

Introduces CrewAI as an open-source framework for multi-agent automation built from Flows (the process manager: state, events, branching) and Crews (teams of role-playing agents). It recommends starting with a Flow and using a Crew inside a Flow step when a task needs autonomous collaboration.

## Key claims

- Flows provide state management, event-driven execution and conditional logic, loops and branching.
- Crews provide role-playing agents with goals and tools, autonomous collaboration and delegation.
- Recommended architecture: a Flow for the application, Crews inside Flow steps where needed.
- Self-reported adoption: over 100,000 developers certified through community courses.
