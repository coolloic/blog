## Summary

A short gateway page. It sets the preconditions for prompt work and routes readers to the best-practices reference, a metaprompt notebook for generating first drafts, and interactive tutorials (written for Claude 3, so superseded where they differ).

## Key claims

- Before prompt engineering you need three things: defined success criteria, a way to test against them empirically, and a first-draft prompt.
- Not every failing eval is a prompt problem; latency and cost are often fixed more easily by switching models.
- A metaprompt (prompt generator) can produce a first draft to iterate on.
