## Summary

States that AutoGen is archived: no bug or security fixes, features or support. It remains for reference only and should not be used in production. It still documents the three-layer architecture and AutoGen Studio, and points users to Microsoft Agent Framework with a migration guide.

## Key claims

- AutoGen is archived; unpatched vulnerabilities may remain; production use is advised against.
- New projects should use Microsoft Agent Framework.
- Architecture: Core API (message passing, local and distributed runtimes, .NET and Python), AgentChat API, Extensions API.
- AutoGen Studio is a no-code prototyping GUI, explicitly not production-ready.
- Python 3.10+.
