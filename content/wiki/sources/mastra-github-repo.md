## Summary

The repository is dual-licensed: content under any `ee/` directory (e.g. auth, agent-builder and editor enterprise modules) uses a separate enterprise licence; everything else is Apache 2.0. GitHub therefore reports the licence as "Other".

## Key claims

- `ee/` directories (e.g. `@mastra/core/auth/ee`, `@mastra/editor/ee`) are under `ee/LICENSE`; the rest is Apache 2.0.
- About 29.5k GitHub stars as of 2026-11-14.
- `@mastra/core` latest is 1.83.0 (2026-11-12), up from 1.0 in 2026-01: a fast minor-release cadence.
