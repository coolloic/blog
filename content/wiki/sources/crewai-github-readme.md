## Summary

Describes CrewAI as a lean, standalone Python framework with its own primitives that does not depend on other agent frameworks, with Crews for autonomy and Flows for precise control. Describes the commercial AMP suite.

## Key claims

- Standalone: its own primitives for agents, tasks, crews and flows, without depending on other frameworks.
- MIT licence; Python >=3.10,<3.14; uv for dependency management.
- About 60.9k GitHub stars (2026-11).
- CrewAI AMP adds managed deployment, tracing, a control plane, security and support, cloud or on-premise.
