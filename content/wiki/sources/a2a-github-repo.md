## Summary

The README describes A2A as an open-source Linux Foundation project, now part of the Agentic AI Foundation, licensed Apache 2.0, and lists official SDKs and headline features.

## Key claims

- Governance: Linux Foundation project contributed by Google, part of the Agentic AI Foundation (AAIF).
- Official SDKs (as of 2026-11-14): Python `a2a-sdk`, Go `github.com/a2aproject/a2a-go`, JavaScript `@a2a-js/sdk`, Java (Maven, `a2a-java` repo), .NET `A2A`, Rust `a2a-lf`.
- Features: JSON-RPC 2.0 over HTTP(S), Agent Card discovery, synchronous, streaming (SSE) and async push interactions, text/file/JSON data, enterprise auth and observability.
