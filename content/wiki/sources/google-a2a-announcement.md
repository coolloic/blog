- **Author/publisher:** Google
- **Date:** 2025-04-09
- **Original:** [Announcing the Agent2Agent Protocol (A2A)](https://developers.googleblog.com/en/a2a-a-new-era-of-agent-interoperability/)

## Summary

Google introduced A2A with 50+ technology and services partners as an open protocol for agents built by different vendors to collaborate. A client agent formulates tasks; a remote agent acts on them.

## Key claims

- Five principles: agentic (agents collaborate without being reduced to tools), built on existing standards (HTTP, SSE, JSON-RPC), secure by default, support for long-running tasks with humans in the loop, modality agnostic.
- Four capabilities: capability discovery via a JSON Agent Card; task management with a lifecycle and outputs called artifacts; collaboration via messages; UX negotiation via typed parts.
- Positioned as complementary to MCP: MCP gives agents tools and context; A2A handles communication between agents.
