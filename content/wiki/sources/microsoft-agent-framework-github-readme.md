## Summary

Entry point for the Python and .NET SDKs (Go lives in `microsoft/agent-framework-go`). Lists the feature set and gives quickstarts against Microsoft Foundry.

## Key claims

- Packages: `agent-framework` (pip), `agent-framework-lab` for experimental modules; NuGet `Microsoft.Agents.AI` and `Microsoft.Agents.AI.Foundry`.
- Features: middleware, workflows with sequential/concurrent/handoff/group patterns plus checkpointing, streaming, human-in-the-loop and time-travel; built-in OpenTelemetry; YAML declarative agents; DevUI for local debugging; Foundry hosted agents; Agent Skills; AF Labs (benchmarking, RL, research).
- Licence: MIT. About 14.7k GitHub stars as of 2026-11.
