## Contradictions

- subagents, claude-agent-sdk: subagents.md says every subagent starts in its own fresh context window. claude-agent-sdk.md (citing claude-agent-sdk-subagents-docs) says a fork (subagent_type "fork") copies the parent conversation, and that subagents run in the background by default. This is an exception that is now documented, not a direct disagreement, so it is not flagged.
- subagents, deep-research-agents: subagents.md lists search, implementation and review as parallelisable sub-tasks. deep-research-agents.md (citing Anthropic's multi-agent research post) advises against multi-agent setups for tightly coupled work like most coding. This is a tension, not a contradiction: subagents.md already tells readers to delegate only when sub-tasks are truly independent.
- **flagged** agent-loop, anthropic-messages-api: agent-loop (Anatomy of a Modern AI Agent) says a turn without tool calls ends the loop, and its sketch returns on it. anthropic-messages-api (Messages API reference, server tools docs) documents pause_turn, which must be resent to continue, and max_tokens truncation: turns with no client tool calls that should not end the loop. Note added on agent-loop.
- **flagged** agent-design-patterns, human-in-the-loop: agent-design-patterns (Google Cloud guide) calls human-in-the-loop 'one of the strongest guardrails'. human-in-the-loop (Meta Rule of Two, Anthropic autonomy study) says blindly approved confirmations still fail, HITL does not replace sandboxing or least privilege, and per-step approval does not scale. Note added on agent-design-patterns.
